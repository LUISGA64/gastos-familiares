## 🎯 Principios de Color Pastel Aplicados

### ✅ Pastel Moderno
- Saturación media-alta (no apagado)
- Luminosidad media (no muy claro ni oscuro)
- Vibrante pero suave

### ✅ Empresarial
- Colores profesionales
- No infantiles
- Transmiten confianza

### ✅ Agradable
- Fácil de mirar
- No cansan la vista
- Emocionalmente positivos

### ✅ Accesible
- Contraste WCAG AA
- Legible en tema claro y oscuro
- Bordes definidos

## 📐 Especificaciones Técnicas

### Variable - Púrpura Pastel

**Tema Claro:**
```css
background-color: #c084fc;  /* HSL: 270, 95%, 76% */
color: #faf5ff;             /* HSL: 270, 100%, 98% */
border: 1px solid #d8b4fe;  /* HSL: 270, 95%, 85% */
```

**Tema Dark:**
```css
background-color: #a855f7;  /* HSL: 270, 91%, 65% */
color: #faf5ff;             /* HSL: 270, 100%, 98% */
border-color: #c084fc;      /* HSL: 270, 95%, 76% */
```

### Pendiente - Naranja Pastel

**Tema Claro:**
```css
background-color: #fb923c;  /* HSL: 27, 96%, 61% */
color: #fffbeb;             /* HSL: 48, 100%, 96% */
border: 1px solid #fdba74;  /* HSL: 34, 97%, 72% */
```

**Tema Dark:**
```css
background-color: #f97316;  /* HSL: 24, 95%, 53% */
color: #fff7ed;             /* HSL: 33, 100%, 96% */
border-color: #fb923c;      /* HSL: 27, 96%, 61% */
```
